# Lydfiler for Jakthund-appen

Plasser dine lydfiler her:

- `rype.mp3` - Rype-lyd som spilles av:
  - Ved oppstart (hvis "Lyd ved oppstart" er aktivert i innstillinger)
  - Når en milepæl oppnås (hvis "Lyd ved milepæler" er aktivert i innstillinger)

## Støttede format
- MP3
- WAV
- OGG

Hvis du ikke har en lydfil, kan du finne fritt tilgjengelige rype-lyder på:
- Zenodo (https://zenodo.org/)
- Xeno-canto (https://www.xeno-canto.org/)
- Freesound (https://freesound.org/)
