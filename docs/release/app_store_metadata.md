# App Store Metadata

## App Identity
- App name: Fuglehund
- Subtitle: Offline jaktlogg for fuglehunder
- Support email: support@gundogtracker.app

## Short Description
Fuglehund gjør det enkelt å loggføre økter, følge fremgang og bygge historikk for fuglehunden din, også når du er offline.

## Long Description
Fuglehund er laget for deg som vil ha en enkel og pålitelig jaktlogg for fuglehunder.

Loggfør økter, følg hundens utvikling og bygg en historikk du faktisk bruker i trening og jakt. Appen er bygget offline-first, slik at du kan registrere data ute i felt og synkronisere senere.

Med Fuglehund kan du:
- registrere hunder og holde oversikt over dem på ett sted
- loggføre økter med sted, notater, poeng og media
- følge fremgang over tid med statistikk og milepæler
- dele tilgang til hunder med andre når det trengs
- bruke appen trygt også uten dekning

Fuglehund er laget for ekte bruk i hverdagen, med fokus på oversikt, stabilitet og enkel logging.

## Key Bullet Points
- Offline-first logging av hunder og økter
- Statistikk og milepæler som gjør utviklingen synlig
- Bilder og media knyttet til hund og økter
- Deling av hunder med familie, treningspartnere eller medeiere
- Bygget for enkel bruk ute i felt

## Privacy And Permissions Notes
- Location:
  Brukes for å lagre hvor økter skjer og vise ruter på kart.
- Camera:
  Brukes når brukeren vil ta bilde av hund eller øktmedia.
- Photo library:
  Brukes når brukeren vil velge eller lagre bilder og videoer i appen.
